The engine’s is 32. Uncapping it plays every note, which is not the game — a level written against the pool depends on the stealing — but it is how the pool’s effect gets measured.

Take either off to compare against a recording of the game made with that effect disabled. Each removes the effect’s return, not its send — the send still feeds the output clip.
